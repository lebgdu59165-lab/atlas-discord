# Annonces automatiques Twitch

Dans le tableau de bord du serveur, ouvrez **Intégrations**, activez les annonces, renseignez une chaîne Twitch, un salon textuel Discord et le message, puis enregistrez. Les variables disponibles sont `{name}`, `{title}`, `{game}` et `{url}`. Le lien Twitch est toujours inclus ; les mentions ne déclenchent pas de notification de groupe.

Le bot vérifie l’API officielle Twitch toutes les soixante secondes, indépendamment du site Render. Lorsqu’il détecte un live, une annonce est placée dans la file persistante. Son identifiant Twitch empêche une seconde annonce pour le même live et le même serveur, même après un redémarrage ou le nettoyage des anciennes tâches. Si un live est déjà commencé au moment de l’activation, il sera annoncé lors de la première détection.

Configurez `TWITCH_CLIENT_ID` et `TWITCH_CLIENT_SECRET` dans le fichier privé du bot. Aucune clé Twitch n’est nécessaire sur le site ; elles ne figurent jamais dans les réponses de l’API du tableau de bord. Les identifiants permettent d’obtenir et de valider un jeton d’application Twitch, renouvelé automatiquement lorsqu’il expire ou est révoqué. Sources : [Get Streams](https://dev.twitch.tv/docs/api/reference/#get-streams), [jetons d’application](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#client-credentials-grant-flow), [validation](https://dev.twitch.tv/docs/authentication/validate-tokens).

Le panneau affiche le dernier contrôle, l’état en direct/hors ligne, une erreur de détection ou d’envoi et la dernière annonce publiée. Le bot vérifie l’appartenance du salon au serveur et ses droits d’accès/envoi. Une configuration désactivée ou changée annule les annonces encore en attente. Les erreurs transitoires d’envoi sont retentées jusqu’à trois fois dans une courte fenêtre, avec un nonce Discord identique pour limiter les doublons. Une livraison interrompue à un instant incertain peut demander un contrôle manuel dans le suivi des actions.

L’hébergement gratuit et Twitch peuvent subir des interruptions. Un live très bref entre deux contrôles peut être manqué. La surveillance s’arrête lorsque le bot s’arrête ; reconnectez-vous au compte Wispbyte au moins toutes les deux semaines pour conserver le serveur gratuit actif. Certains démarrages demandent de regarder une publicité dans le panneau Wispbyte. Un contrôle datant de plus de deux minutes est signalé comme interrompu sur le tableau de bord. Les tests utilisent des lives simulés dans une base isolée ; un premier démarrage réel de live doit encore confirmer l’annonce de bout en bout.
